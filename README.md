# Digital Target — Screen Studio

This repository contains **Digital Target Screen Studio**, a professional screen recorder and screenshot tool for Windows 10/11 built by Digital Target.

➡️ The application lives in [`digital-target-screen-studio/`](digital-target-screen-studio/) — see its [README](digital-target-screen-studio/README.md) for features, build and installation instructions, architecture, testing and licensing.

Windows installers (NSIS setup and portable `.exe`) are produced by the [GitHub Actions workflow](.github/workflows/screen-studio.yml) and attached to each run as the `windows-installer` artifact.
